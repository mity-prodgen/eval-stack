A bootstrap interval of a 0-of-n rate is [0.0, 0.0], which overstates certainty: with 0 events in n trials the 95% upper bound is about 3/n (rule of three), i.e. 2.5-3.2% for the noise-flip n here (94-118 item-runs) and about 5-6% for the post-1 flip n (47-59 items).

A post-1 flip rate inside the noise-flip interval (or under 3/n when noise flip is 0) for the same judge and arm is not distinguishable from run-to-run noise at this n.
